# Asset licences

What ships with Machine Brigade that was not written for it, and what was generated by the repository's own tools. Only
CC0 and CC-BY (or licences as free, such as the Sonniss GDC licence below) are used; nothing is AI-generated audio.

## Sound

| Path | Source | Licence |
|---|---|---|
| `Assets/MachineBrigade/Resources/Audio/*` (recorded effects: mg, cannon, explosions, loops ...) | Sonniss #GameAudioGDC bundles, Kenney UI Audio, OpenGameArt; per file in `Assets/MachineBrigade/Resources/Audio/CREDITS.md` | Sonniss GDC licence (no attribution), CC0 1.0 |
| `Assets/MachineBrigade/Resources/Audio/sfx/*` (fix pass L7, replaces prompt 34's `p34`: shots, launches and blasts by size class and round, hits by surface, wrecks, crashes, small-arms clusters, engines by class, ship and train horns and loops, flares, incoming-shell whistles; `envelopes.txt` is their RMS envelopes) | Premixed by `Tools/sfx/build_sfx.py` (numpy, scipy, soundfile): the main layer of the guns from 20 mm and of the blasts is a recorded Sonniss clip of this folder's old banks (listed in `Resources/Audio/CREDITS.md`), pitched and layered; the sub and tail layers, the small arms, the hits, engines, horns, flares and whistles are synthesised from noise, sines and filters with fixed seeds; no AI | Sonniss GDC licence for the recorded layers (modification allowed, no attribution); the rest original work of this repository |
| `Assets/MachineBrigade/Resources/Audio/Music/*` | Composed and rendered by `Tools/music` (FluidSynth with the FluidR3_GM SoundFont, MIT) | Original work of this repository |
| `SoundSynth` (runtime stand-ins) | Synthesised in code (`Scripts/Game/Audio/SoundSynth.cs`) | Original work of this repository |

## Models and textures

Built by the Blender scripts in `Tools/blender` (`build_assets.py`); see `Docs/models` and `Docs/art`. No third-party
